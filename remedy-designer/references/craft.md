# Craft bar (positive doctrine)

Load before any UI edit. Bans live in [bans.md](bans.md) and `vendor/` — this file is what good looks like.

## Direction Lock fields

Emit the Remedy announce block before code. Meanings:

| Field | Meaning |
|-------|---------|
| `read` | Audience · vibe · aesthetic family or product DNA |
| `type` | Display + body intent (named faces or “tokenized from DESIGN.md”) |
| `palette` | Color anchor hex/OKLCH family **or** `DESIGN.md` |
| `risk` | One concrete signature move (pick from menus below) |
| `avoid` | Named default cluster you are deliberately not using. If the brief does not pin type, name a second-wave default (font five, reflex cluster, or Operate costume) — see SKILL.md |
| `prefs` | `account` · `project` · `both` · `none` — which preference files were loaded |

**Ask once** only when vibe/DNA genuinely forks the build. Otherwise infer and commit.

## Signature-risk menus

Pick **one**. Vague “make it unique” is not a risk.

### Persuade / Experience

- Asymmetric hero type lockup
- Editorial split (text plane vs full-bleed media)
- Kinetic / scroll-authored type moment
- Material or tactile surface system
- Photographic full-bleed with restrained chrome
- Custom illustration system (consistent stroke/weight)
- Unconventional section rhythm (not hero → 3 cards → CTA)

### Operate

- Named DNA + diverge (e.g. Linear-dense + warmer accent)
- Stripe-data tables / denser data voice
- Apple-airy shell / softer Notion density
- Never “marketing uniqueness” on the product floor

### Read

- Calm authority type scale + measure (~65ch)
- Quiet chrome; comprehension hierarchy first

## First-viewport gates

| Mode | First viewport may contain | Must not |
|------|----------------------------|----------|
| **Persuade** | Brand, one headline, one support line, one CTA group, one dominant visual | Stats, chips, cards, schedules, address blocks, feature grids |
| **Experience** | The work itself leading; minimal chrome | SaaS feature grid, fake metrics |
| **Operate** | Task chrome: nav, primary view, scannable controls | Grain, glow mesh, custom cursor, hero theater |
| **Read** | Nav + title + start of content | Marketing feature rows |

## Composition positives

- Brand as a hero-level signal on branded Persuade surfaces (brand test: remove nav — still recognizable)
- One job per section: one headline, usually one short support line
- Cards only when they wrap a user interaction; never in the hero
- Full-bleed heroes on promotional surfaces (edge-to-edge visual plane)
- Real visual anchor: product, place, atmosphere, or context — not decorative gradient alone
- Prefer intentional asymmetry over three equal feature cards

## Type and color process

1. Commit type pairing and palette in Direction Lock **before** markup.
2. Use tokens / CSS variables; no mid-render hex improvisation when a system exists.
3. Persuade/Experience: refuse Inter / Roboto / Arial / system-ui as the only display voice.
4. Operate: one competent product sans with intent is allowed; hierarchy via weight and muted color.
5. Honor locked `DESIGN.md` / brief over saturated-pattern warnings.
6. **Copy gate, only if copy in the diff changed.** No extra skill. Fail and rewrite the line: “not just X, it’s Y”; invented or round metrics; lorem or feature-one-two-three; a control that does not name its action. Skip when the brief says keep the copy.

## Motion intent

- Persuade/Experience ship: at least 2–3 authored moments (entrance, hover, or scroll) — not identical section fades
- Operate: frequency-gate — dense daily actions often need **no** animation
- Prefer transform/opacity; respect `prefers-reduced-motion`
- Motion skills (genjutsu / Impeccable `animate`) run **after** structure

## Ceiling / floor

- **Ceiling** (Persuade/Experience): distinctive type, atmosphere, signature motion allowed
- **Floor** (Operate): calm, scannable, native expectations; brand in precise details only
- **Leak examples:** film grain, radial glow, custom cursor, gradient mesh, parallax on dashboards/settings = failure

## Pre-emit (5 axes, 1–5)

Before claiming done, score:

1. **Hierarchy** — clear focal point; scanning works
2. **Specificity** — could not swap brands without noticing
3. **Restraint** — decoration earns its place
4. **Mode-fit** — ceiling/floor respected
5. **Anti-slop** — bans and operate-tells clear

Any axis **below 3** → one revision pass, then stop. Any axis **below 5** includes one concrete observation (what you saw, where). A row of bare fives is not a score. Narrow edits skip this block.
