# Assignment matrix

Legend: **Primary** = only layout builder. **Support** = contracts/detect (not a second builder). **Secondary** = only if trigger matches. Detect/Audit = non-builder lane after build.

Full router lives in SKILL.md; this file is the deep reference when ambiguous.

## Build

| Assignment | Mode | Primary | Support / optional secondary | Detect | Audit |
|------------|------|---------|------------------------------|--------|-------|
| Greenfield standalone marketing HTML | Persuade | Hallmark | — | Impeccable detect | slop-cop |
| Marketing inside React/Next + DS | Persuade | Impeccable | Taste if dials set | Impeccable → uxskill | Vercel guidelines |
| Multi-page brand with locked DESIGN.md | Persuade | Impeccable | Hallmark study → DESIGN.md only (then stop Hallmark) | both | Vercel |
| Dashboard / settings / admin / app UI | Operate | **product-ui-design** (local skill) | Impeccable contracts/detect; ui-forge if greenfield no DS needs 3 directions | Impeccable → operate-tells → uxskill | Vercel |
| Complex greenfield product, no tokens | Operate | product-ui-design (local skill) | Impeccable init → ux-skill recommend XOR Pro Max; ui-forge for 3 directions | both | Vercel |
| Docs / help / changelog | Read | Impeccable | — | Impeccable | Vercel |
| Portfolio / gallery | Experience | Hallmark (HTML) or Impeccable (framework) | genjutsu if motion is thesis | Impeccable | slop-cop |
| Ecommerce storefront | Split | Campaign LP HTML → Hallmark; framework campaign → Impeccable; PDP/cart/checkout → Operate path | — | both | Vercel |
| Mobile web / PWA | same as surface | Same primary as desktop mode | Impeccable `adapt` after | both | Vercel |
| Design system / tokens | — | Impeccable document/extract | ux-skill recommend if cold-start | Impeccable on samples | — |
| Native-feeling mobile UI in code | Operate | Same Operate primary as a dashboard | Impeccable native refs; genjutsu after structure if motion was asked | Impeccable audit.native | — |

## Non-build (no layout builder)

| Assignment | Lane | Do not use |
|------------|------|------------|
| Motion polish | genjutsu cast (or Impeccable animate if light) | Hallmark, Taste, ui-forge as layout |
| Audit / grade only | Impeccable detect → uxskill → one audit owner | Any builder. Both auditors only if the user said full audit |
| De-slop existing UI | kill-ai-slop if installed (report, then confirmed fixes). Else detect on touched paths + second-wave avoid | Any layout primary. Do not rebuild the page to “clean” it |
| Redesign keep IA/copy | Hallmark redesign if HTML page; else Impeccable | Taste + Hallmark together |
| Study reference | Hallmark study → DESIGN.md then stop | Building before diagnosis |
| Claude Design / Open Design handoff | Ingest → Impeccable polish/document | Hallmark theme pick over locked brand |
| Cold-start style exploration | ux-skill recommend XOR UI/UX Pro Max | Both together |
| UX critique / ship | Impeccable critique → polish | slop-cop as sole critique |
