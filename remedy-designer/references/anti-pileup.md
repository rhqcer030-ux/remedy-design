# Anti-pileup

Skills fight when co-invoked. Remedy forbids stacking builders.

1. **One primary builder** per assignment.
2. **Hallmark XOR Impeccable for layout.** Hallmark = greenfield standalone page variety. Impeccable = framework / app / design-system work.
3. **Taste is never default.** Only when dials are explicit or Taste is named. Global install availability is **not** an invitation.
4. **frontend-design is reference doctrine**, not a co-builder beside Hallmark, Impeccable, or product-ui. Do not invoke it as a second layout skill.
5. **ux-skill XOR UI/UX Pro Max** on one recommend pass.
6. **genjutsu never owns layout** — motion after structure.
7. **Detect lane is mandatory on ship;** builders never skip it.
8. **Persuade spectacle must not leak into Operate.**
9. **Hallmark `study` stops at DESIGN.md.** Do not keep building with Hallmark after study unless the job is greenfield standalone HTML.
10. **Operate primary is the local product-ui-design skill.** Impeccable supports contracts and detect. It is not a second layout builder. Do not clone the 404 GitHub URL.
11. **kill-ai-slop never owns layout.** It scans existing UI, reports, and edits only groups a person confirmed. It does not pick a theme.
12. **One audit owner per ship.** Persuade/Experience → slop-cop. Framework, Operate, Read → Vercel guidelines. Both only on an explicit full audit.
13. **ui-craft is installed and is not a builder.** A URL scanner is not a ship step. diagram-design runs only when the deliverable is a diagram.

## Why

- Hallmark biases toward self-contained HTML/CSS pages — poor drop-in for React component libraries.
- Impeccable owns `PRODUCT.md` / `DESIGN.md` and Cursor hooks across modes.
- Taste dials conflict with Hallmark’s theme/macrostructure picker when both run.
- Two recommend engines produce competing design systems.
- Stacking frontend-design as a “builder” reintroduces competing aesthetics on top of the chosen primary.
- A second polish pack (ui-craft) or a second slop scanner on every ship doubles the pass and disagrees with the first.
